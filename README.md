# buzzer-with-photocell

گزارش کار ازمایش  buzzer with photocell

نام و نام خانوادگی:مبینا اسحاقی

استاد:اقای دکتر عباسی

عنوان آزمایش: ترکیب buzzer , photocell 


هدف آزمایش:
 هدف از این آزمایش یادگیری نحوه استفاده از فوتوسل و buzzer برای کنترل روشن و خاموش کردن چراغ و تولید صدا بر اساس شدت نور محیط است.

وسایل مورد نیاز:

برد آردوینو (Arduino Uno) 💻

فوتوسل (Photoresistor) 🌞

buzzer 🔊

لامپ یا LED 💡

مقاومت‌ها (برای فوتوسل و LED)

سیم‌ها 🔌

لپ‌تاپ یا کامپیوتر برای برنامه‌نویسی آردوینو 💻

نرم‌افزار آردوینو IDE 🖥️


شرح آزمایش:

1. فوتوسل به پایه آنالوگ آردوینو وصل می‌شود تا نور محیط را اندازه‌گیری کند. 🌞

2. لامپ و buzzer به پایه‌های دیجیتال آردوینو متصل می‌شوند.

3. در برنامه آردوینو، نور محیط از فوتوسل خوانده می‌شود.

4. اگر نور زیاد باشد، LED خاموش و buzzer روشن می‌شود. اگر نور کم باشد، LED روشن و buzzer خاموش می‌شود.

نتیجه‌گیری: این آزمایش نشان می‌دهد که با استفاده از فوتوسل می‌توان بر اساس شدت نور محیط، عملکرد دستگاه‌ها مانند LED و buzzer را کنترل کرد.
